# GitHub 热报视觉方向探索

本轮只评估榜单首页的视觉与信息组织，仓库与数字为静态演示内容，不代表实时数据。共同任务是快速看懂当期新增 Star、按语言筛选、搜索、收藏和进入详情。目标设备为桌面 1280×900 与手机 390×844。选定方向后再深化交互、详情和异常状态。

## A 清晰索引

- 北极星：像查阅一份维护良好的技术索引，一眼找到仓库与关键数字。
- 调性：安静 2/5、精致 4/5、密度 4/5、轻 2/5、严肃 4/5。开发者需要反复扫读。
- 引擎与骨架：档案管理员；窄左导航 + 通栏榜单，首屏就是完整工具。
- 视觉：冷白画布、墨灰文字、单一深绿动作色；系统无衬线与等宽数字；细分隔代替卡片。
- 记忆点：涨星数字组成稳定、整齐的右侧数字轴。
- 放弃：大 Hero、插图、层层套卡。

## B 深色信号

- 北极星：像看开发社区的市场信号，最值得点开的项目先浮出水面。
- 调性：安静 3/5、精致 4/5、密度 4/5、重 4/5、严肃 4/5。夜间使用与数据对比优先。
- 引擎与骨架：暗室中的数据终端；顶部通栏筛选，榜首横向铺开，余下仓库是紧凑队列。
- 视觉：炭黑、雾灰与荧光黄绿形成高对比；大号等宽数据承担主视觉，不用装饰性发光。
- 记忆点：榜首新增 Star 的数字尺寸与列表形成清晰落差。
- 放弃：终端框拟物、彩色状态灯和炫技动画。

## C 编辑榜单

- 北极星：像读一份有判断力的开源观察，先读项目，再比较名次。
- 调性：安静 2/5、精致 4/5、密度 3/5、轻 3/5、严肃 3/5。适合发现与阅读。
- 引擎与骨架：技术刊物目录；整版标题下是一大两小的非对称项目排版，下接连续榜单。
- 视觉：偏冷的纸白、深墨绿与朱红强调；粗细明显的无衬线标题，正文较宽松。
- 记忆点：第一名以项目名称与语言色块形成封面感，但操作仍在同一首屏。
- 放弃：杂志拟物纸纹、文章式长文和营销口号。

三套骨架分别是侧栏索引、通栏数据主角、非对称编辑拼贴；字体尺度、色彩身份和主视觉也不同。用户于本轮选择 A「清晰索引」。深化版位于 `prototype-a/`，保留侧栏索引与数字轴，并提供可操作的本地演示状态。B、C 仅作为探索记录保留。
