# A「清晰索引」前端原型

直接打开 `index.html`。这是设计验证用的静态原型，不接入 GitHub、采集任务或翻译 API。仓库简介及所有 Star 数都是演示数据，更新时间固定为 2026-10-17 10:00（北京时间），不应对外当作实时榜单展示。

可操作：日榜/月榜切换、独立的编程语言榜单样本、当前榜单搜索、中英文切换、仓库详情、浏览器本地收藏，以及用户自带 AI Key 的翻译设置流程。列表和详情均提供“翻译简介”；未配置 Key 时打开设置，配置后点击会明确提示静态原型尚未接入翻译服务。原型不会保存真实 Key（仅用当前页面标记模拟“已配置”），请勿输入真实密钥。刷新后收藏与语言选择仍保留，Key 配置状态清空。地址增加 `?state=stale` 可看过期提示，增加 `?state=error` 可看首次加载失败状态。

方向基线：冷白画布、窄侧栏、单行仓库索引、右侧新增 Star 数字轴。手机布局收起侧栏，保留同一任务顺序和操作入口。视觉主次以仓库名与新增 Star 为先，总 Star、语言、数据来源与采集时间为辅。

接入真实数据时，应按 `PRD.md` 使用服务端快照和按语言独立的 GitHub Trending 候选集；简介保持原文，只有用户输入自己的 Key 并主动点击翻译时才通过本站 HTTPS 服务端代理调用 AI；此原型中的静态仓库及 Star 数据只是界面占位。`styles.css` 已包含跟随系统的深色模式变量，但当前尚未完成实际浏览器截图验收。
